# chen-cecilia.github.io

Personal academic website built with Quarto and hosted on GitHub Pages.

## Rebuild

1. Open `chen-cecilia.github.io.Rproj` in RStudio.
2. Run `quarto render` (or click Render Website in the Build pane).
3. The site is generated into the `docs/` folder.
4. Commit and push — GitHub Pages publishes from the `main` branch `/docs` folder.
